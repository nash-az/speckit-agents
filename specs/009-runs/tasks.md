**Input**: `spec.md` (amended 2026-11-06), `plan.md`, `research.md`, `data-model.md`, `contracts/`, `quickstart.md`
in this folder. T001–T012 were built with `/sdd-run` from the operator session (the person's choice, 2026-11-06),
so the run's learnings are gathered; T001 was done by hand before that choice. T013 onward is the amendment after
run 20261106-1204 and its analyze pass; those runs start through the supervisor (FR-027).

Every task keeps the whole suite green on its own commit (`python3 -m unittest discover -s tests`,
`node --test tests/workflow.test.mjs`, `claude plugin test .`): a task that changes behaviour updates the existing
tests that assert the old behaviour in the same task (never delete a test without a replacement that checks the
new rule). Callers move to the 009 functions before the 005 ones are removed.

The indented line under each task is its plain-language summary (FR-028, data-model §7); the dashboard shows it.
