## Lessons
- **Check the branch before committing while a Job runs.** The checkout is the Job's: a docs commit made then (FR-032,
  `8e2adc7`) landed on the Job branch. Do side work in a `/tmp` worktree off `main` (as `fix/live-output` was).
- **Never invent UI text in manual steps.** T022 quoted "Job running: Phases 1–2 of 008", which no banner says.
  Quote the texts from the data model (005 data-model §9 banner table).
- **Steps ask the person to do and paste, never to judge or screenshot** (the note box takes text only). Claude draws
  the conclusion from the pasted output.
- **An example name is not an option.** "cheap" was 003's sample profile name; offering it as if configured confused
  the person.
- **Readers of run events must span every workflow directory.** A run can resume in a new session; anything that
  looks only at the last directory goes blank mid-task.
- **A local model must have tool use and fit the GPU.** macOS gives the GPU about 75% of RAM (48 GB of 64). Tool
  support alone listed `nemotron-3-super` (86 GB) as usable; it is not.
- **One Claude Code session has one API address** (`ANTHROPIC_BASE_URL` is session-wide; docs fetched 2026-11-05).
  Mixing a local implementer with a Claude verifier needs a router; the subscription login must never reach Ollama.
- Ollama 0.34 answers the Anthropic `/v1/messages` format directly. `qwen3.6:27b-q8_0` returned correct parallel
  `Read` calls (39 s with load), 46 GB on the GPU at its default 256K context, so the proofs use a 64k copy.
