# 2026-10-30: lessons from the 004/005 planning session and run 20261030-1515

Plugin-generic lessons (project-specific ones go in a project's own `.sdd/learnings.md`).

- **Browser tasks cannot run inside the run sandbox.** In run `20261030-1515` (003 Phase 11) T053 blocked: the
  sandbox refused to bind a localhost port (`Errno 1`) and Chromium/Chrome would not start ("Failed to create a
  ProcessSingleton"). The run's Playwright also looked for `chromium_headless_shell-1248` while the cache had
  `-1228`, so it fell back to Google Chrome. Planned fix (user's choice): `"allowLocalBinding": true` under
  `sandbox.network` in `.claude/settings.json`, install the headless-shell build Playwright wants, and prove it
  with a sandboxed run of `tests/ui/test_smoke.py` before relying on it. Not done yet.
- **A phase titled "Convergence" holds every open task in earlier phases** (`direct_holds` rule 2). Writing 004's
  tasks.md with a final "Phase 9: Convergence" held all 33 tasks as superseded. Name such a phase only when that
  is meant; check new tasks.md with `bin/sdd-tasks.py plan` right after writing it.
- **Never `.strip()` `git status --porcelain` before cutting `line[3:]`.** The first line starts with a space for
  a modified tracked file; stripping lost the first path's first character in refusal messages (fixed in
  `c041b41` in sdd-launch, sdd-decide, sdd-manual).
- **Runs must record their feature.** Task ids repeat across features (004's T001 is not 003's T001), so linking
  runs to tasks needs `feature` in `.sdd/runs/<id>/workflows.json` (the skill writes it since `b29981d`; older
  runs are matched by spec `**Created**` date).
- **A run started from an interactive session shares this session's working tree and branch.** Edits made during
  it land in its tree. Rule since 2026-10-30: change nothing in the project while `.sdd/run.json` exists; draft
  under `/tmp`.
- **The dashboard showed `Queued` for a task the run had just blocked**, because BLOCKED.md is written only when
  the group finishes. Fixed in `488f06d` ("Blocked (not recorded yet)").
- **`UITestCase.setUpClass` errors instead of skipping** when the browser launches but the dashboard cannot bind
  its port (found by T053; for T065).
